Watch a real AI agent work, live

This page connects to a real, unattended coding agent (daily_agent.py, Gemini-powered) mid-run, against a real GitHub repository. Nothing here is simulated or replayed for effect — every card below is a real tool call, every number is real spend, as it happens.

How this actually works
  1. The agent runs unattended on a schedule (Cloud Run Job), picking one real gap in a repo and fixing it.
  2. As it works, it emits standard AG-UI protocol events (tool calls, step transitions, running cost) through a small, reusable Python adapter.
  3. Those events land in Firestore, one document per event, under agent_runs/<run_id>/events.
  4. A minimal, read-only proxy service watches Firestore server-side and re-emits the same events as a plain SSE stream — no database access from your browser at all.
  5. This page is just a client for that stream: the same event-driven UI components (streaming runtime + atom controllers) render whatever's actually happening, live.
