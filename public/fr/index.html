Catalogue A2UI

A2UI Atomic Catalog, en français

L’A2UI Atomic Catalog (a2uicatalog) est un catalogue open source de 573 composants A2UI typés, les « atomes », avec lesquels un agent IA construit de vraies interfaces au lieu de générer du HTML. Le nom du projet reste en anglais ; le reste du site aussi.

Qu’est-ce qu’A2UI ?

A2UI (Agent-to-User Interface) est un protocole ouvert de Google. L’agent décrit l’interface en JSON ; un moteur de rendu l’affiche avec ses propres composants. L’agent n’envoie jamais de code exécutable. Spécification officielle : a2ui.org (en anglais). Guide pas à pas : What is A2UI? (en anglais).

Ce que contient le catalogue

  • 573 atomes typés (cartes, tableaux, graphiques, formulaires…), chacun avec son contrat de champs dans /spec.json.
  • Un serveur MCP gratuit à https://a2uicatalog.ai/mcp, sans clé d’API ni inscription, inscrit au registre officiel MCP sous ai.a2uicatalog/catalog.
  • Une API REST décrite en OpenAPI 3.1 : POST /api/render renvoie une page HTML complète, et un bac à sable (/api/sandbox) permet de tester sans entamer le quota.
  • Des moteurs de rendu pour le web, Google Meet, Google Apps Script, Google Chat, les hôtes MCP Apps et Android, ainsi que la génération de présentations Google Slides et PowerPoint.

Démarrer

POST https://a2uicatalog.ai/mcp
Content-Type: application/json

{"jsonrpc": "2.0", "id": 1, "method": "tools/list"}

Pour essayer un document A2UI à la main : le bac à sable interactif. Pour parcourir les composants : tous les atomes de A à Z. Documentation d’intégration : /docs/ (en anglais).
