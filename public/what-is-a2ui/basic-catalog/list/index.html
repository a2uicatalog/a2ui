List

ArrangeList

List is part of the Basic Catalog in Google's A2UI v1.0 protocol. This page shows how it behaves so you can build with it. Unofficial, and not affiliated with Google.

    • Remote media was not loaded, so media records element creation and attributes, not playback.
    • Layout and visual quality are not judged.

    Media and links in the examples use example.invalid placeholders. Navigation is intercepted and media is not played.
