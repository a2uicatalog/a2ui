Findings

  • formatCurrency(1234.5, EUR, 0 decimals): the SDK reference gives 1,234 (an exact half rounds to even) and React gives 1,235. The spec states no rounding mode. The cause was inferred, not verified.
  • For 1234.5 EUR with 0 decimals the SDK reference (Python, Babel) gives €1,234 and the React renderer (browser Intl) gives €1,235. Measured cause: Babel rounds exact halves to even, Intl rounds them away from zero (checked on 1233.5, 1234.5 and 1235.5, and Intl with roundingMode halfEven gives €1,234). The implementation guide says to use the platform's native formatting and names no rounding rule, so neither is called wrong. Source: guide in the saved upstream copy (the current v1.0 spec, identical to a2ui.org), read 14 Nov 2026.

DIFF in formatCurrency: for {"value": 1234.5, "currency": "EUR", "decimals": 0} the SDK reference gives €1,234 and the browser, through the renderer, gives €1,235. The cause is how an exact half is rounded: the Python library the SDK uses rounds half to even (1234.5 gives 1,234; 1235.5 gives 1,236), while the browser rounds half away from zero (1234.5 gives 1,235).
