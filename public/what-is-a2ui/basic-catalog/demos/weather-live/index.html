Weather, live agent

Ask for the weather in any city and watch a live A2UI agent answer: a Worker looks the city up, fetches the forecast and writes the card in code, and a bar shows where each millisecond went.

Letters mark the request form, numbers the reply; the lists name each part. Only each part was tested, not each combination.

    Use case

    Fill in the form at the top of the screen. It is A2UI too, drawn by the same renderer.

    Beyond the official renderer, and optional: labels tied to their inputs, Enter sends, error and reason text linked to the inputs, a reason shown when the button is off, and a check that To is not before From.

    Airline text comes from frozen data for 60 airports, taken from Wikipedia on 14 Nov 2026. Any other place still gets the weather and the distance estimate.

    Runs on our Worker. No model, no tokens.
