    What WebMCP is doing here

    WebMCP is a proposed browser API that lets a web page offer tools to an agent. The page registers them with document.modelContext.registerTool, and an agent in or alongside the browser can call them, in the same tab you are looking at. Here the three tools below act on the very basket on this page, so you watch the state change as the agent works, instead of reading about it afterwards.

    The tools return small facts as JSON: items, quantities and the total in whole pence. The one tool that matters, checkout, is gated: it only completes when you click in the box that opens. An agent cannot place the demo order by itself, and the buttons above work the same with no agent at all.

    The three tools this page registers
    ToolWhat it doesInput
    add_to_basketAdds an item to the basket.sku (one of the six), quantity 1 to 9
    view_basketReads the basket. Marked read only. Changes nothing.none
    checkoutAsks to place the demo order. Only completes if you click Place demo order.none

    Try it

    In Chrome with chrome://flags/#enable-webmcp-testing turned on, open the developer tools console on this page and paste this. It lists the tools and calls them.

    // In the console of this tab (Chrome with the WebMCP flag on):
const mc = document.modelContext;
const tools = Array.from(await mc.getTools());
console.log(tools.map(t => t.name));            // add_to_basket, view_basket, checkout
const call = (name, args = {}) => mc.executeTool(tools.find(t => t.name === name), args);
// If your build wants the input as a JSON string, use JSON.stringify(args) instead of args.
console.log(await call('add_to_basket', { sku: 'tea', quantity: 2 }));
console.log(await call('view_basket'));
console.log(await call('checkout'));            // waits until you click Place demo order or Cancel

    The exact shape of executeTool and of tool results has changed between Chrome builds, so treat this as a starting point. Unofficial demo, not affiliated with Google or the Chrome team.
