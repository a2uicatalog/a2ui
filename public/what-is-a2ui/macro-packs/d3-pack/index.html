Six examples

Each one was drawn from the pack's own demo parameters and saved as a file when this page was built; this page does not call a server.

How the sizes were measured (15 Nov 2026): the call is the compact JSON {"macro", "params"}; the message is the compact JSON of the first A2UI message the client receives (createSurface, with its data model holding the SVG as a data: URL). Both are UTF-8 bytes.
