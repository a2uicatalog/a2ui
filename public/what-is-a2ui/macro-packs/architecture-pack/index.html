The architecture pack

One macro, arch_motion. It takes nodes, edges, messages and groups and returns two SVG drawings, a wide view and a narrow view, with motion that plays once and stops.

Limits read from the code: up to 12 nodes, 16 edges, 12 messages and 4 groups.

The guardrail

Every drawing must pass the d3 pack's verify_rich check: animations end within 5 seconds, at most 20 elements are animated, there are no CSS keyframes and nothing is loaded from outside the file. Each picture on this page passed it when it was rendered.

Layout check

Our own layout checker measures the real text and path geometry in a browser. On 14 and 15 November 2026 it reported 0 problems over 12 demo SVGs. This is a measured result of our own checker, not an outside audit.

The container-diagram preset

On a narrow screen the narrow view is shown. If your system asks for reduced motion, the still picture is shown first; the switch above each picture changes it.
