# Time Estimate

Displays the estimated duration required to fully read or complete an article.

## Surfaces

web, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| minutes | integer. The estimated reading time in minutes. |

## Example payload

```json
{
  "type": "time_estimate",
  "minutes": 1
}
```
