# Related Posts Grid

Displays a curated grid of preview cards for complementary reading material.

## Surfaces

web, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| posts | array. Objects containing title, url, and optional topic. |

## Example payload

```json
{
  "type": "related_posts_grid"
}
```
