Message Lanes

The A2UI pitch, drawn: small packets stream from an agent node on the left down curved lanes into a surface node on the right, leaving light trails; every arrival makes the surface flash and unfolds a small card outline inside it, the newest on top, older ones fading. Labels for both nodes are agent-supplied (up to 24 characters each). Optional eyebrow/title/body copy. Honours prefers-reduced-motion (one pre-simulated frame with packets mid-flight), pauses offscreen, DPR-aware. Dark backgrounds only. Every option is an enum or a clamped int; colours must be #rrggbb.

FieldType

to_labelstring. Label under the right node. Default "surface".optional
lanesinteger. Number of lanes, clamped 1-6. Default 4.optional
rate"slow" | "normal" | "fast" (optional, default "normal"). Packet speed.optional
titlestring. Headline overlaid on the scene.optional
eyebrowstring. Small uppercase label above the title.optional
bodystring. Copy under the title (markdown inline supported).optional
align"left" | "center" | "right" (optional, default "center")optional
colorsarray of 1-4 "#rrggbb" strings. Default sky/violet/pink; the first colours the agent node, the second the surface.optional
background"#rrggbb". Default "#070a12". Keep it dark.optional
heightinteger. Panel height in px, clamped 200-900. Default 320.optional
