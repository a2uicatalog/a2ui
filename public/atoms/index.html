A2UI Catalog / atoms

All 573 A2UI components

The A2UI Atomic Catalog, A to Z. Each atom is a typed A2UI component an AI agent sends as declarative JSON; the client renders it, so no model-written HTML reaches the page. Every entry links to its fields, an example payload and a live preview. Agents can search the same catalog through the MCP server (find_atoms).
