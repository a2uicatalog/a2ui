# Blockquote

Styled pull-quote with optional attribution line

## Surfaces

web, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| text | string |
| attribution | string (optional) |

## Example payload

```json
{
  "type": "blockquote",
  "text": "A concise description of the content."
}
```
