# Key Takeaways

Displays a highlighted summary box containing critical bullet points from an article.

## Surfaces

web, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| points | array. Core sentences highlighting the key learnings. |

## Example payload

```json
{
  "type": "key_takeaways",
  "points": [
    "First key point",
    "Second key point",
    "Third key point"
  ]
}
```
