# Cli Command

Displays a copyable single-line command-line prompt for terminal execution.

## Surfaces

web, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| command | string. The exact shell command to be copied and executed. |

## Example payload

```json
{
  "type": "cli_command",
  "command": "npm install a2ui"
}
```
