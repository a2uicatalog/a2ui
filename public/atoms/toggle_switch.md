# Toggle Switch

Renders a visual on/off switch.

## Surfaces

web, google-meet-stage, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| label | string |
| is_checked | boolean |
| name | string |

## Example payload

```json
{
  "type": "toggle_switch",
  "label": "Toggle Switch",
  "is_checked": true,
  "name": "Toggle Switch"
}
```
