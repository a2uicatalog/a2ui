# Figma Embed

Renders a real-time collaborative preview referencing explicit Figma design canvas artboards.

## Surfaces

web, mcp-apps

## Fields

| Field | Type |
|---|---|
| embed_url | string. Absolute sharing path generated by Figma. |

## Example payload

```json
{
  "type": "figma_embed",
  "embed_url": "https://example.com"
}
```
