# Comparison Morph

Draggable before/after slider revealing two text panels side by side

## Surfaces

google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| before | {label (optional), text} |
| after | {label (optional), text} |
| title | string (optional) |

## Example payload

```json
{
  "type": "comparison_morph"
}
```
