# Repo Links

Formatted GitHub repo link list at end of article

## Surfaces

web, google-meet-stage, email, pdf, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| links | [{'label': 'string', 'url': 'string'}] |

## Example payload

```json
{
  "type": "repo_links",
  "links": [
    {
      "label": "GitHub",
      "url": "https://github.com/a2uicatalog/a2ui"
    }
  ]
}
```
