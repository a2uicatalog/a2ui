# Rating Comparison

Renders a comparison of multiple items based on star ratings or numerical

## Surfaces

web, google-meet-stage, google-chat, email, pdf, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| items | array |

## Example payload

```json
{
  "type": "rating_comparison",
  "items": [
    {
      "label": "Item 1"
    },
    {
      "label": "Item 2"
    }
  ]
}
```
