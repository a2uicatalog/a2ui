# Embed Stackblitz

Renders an integrated live development engine frame executing StackBlitz workspace code.

## Surfaces

web, mcp-apps

## Fields

| Field | Type |
|---|---|
| project_id | string. Folder identity indicator for active workspace. |

## Example payload

```json
{
  "type": "embed_stackblitz",
  "project_id": "Project id"
}
```
