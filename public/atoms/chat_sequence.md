# Chat Sequence

Animated conversation thread with user/assistant bubbles

## Surfaces

google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| messages | array of {role (user|assistant), name (optional), text} |

## Example payload

```json
{
  "type": "chat_sequence"
}
```
