# User Greeting

Personalised greeting showing the active user's Google account email. Works on Google Apps Script only.

## Surfaces

google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| prefix | string (optional). The greeting prefix. Default is "Hello". |

## Example payload

```json
{
  "type": "user_greeting"
}
```
