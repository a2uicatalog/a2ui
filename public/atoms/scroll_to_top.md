# Scroll To Top

Renders an interactive button providing smooth automated viewport reset to page top.

## Surfaces

web, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| behavior | string: smooth | auto. Scroll animation profile. |

## Example payload

```json
{
  "type": "scroll_to_top",
  "behavior": "smooth"
}
```
