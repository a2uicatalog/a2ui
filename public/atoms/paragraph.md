# Paragraph

Prose paragraph block (alias for body, google-apps-script-web only)

## Surfaces

google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| text | string |

## Example payload

```json
{
  "type": "paragraph",
  "text": "A concise description of the content."
}
```
