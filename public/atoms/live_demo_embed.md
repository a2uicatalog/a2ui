# Live Demo Embed

Embeds a live interactive demo or sandbox within the article.

## Surfaces

web, mcp-apps

## Fields

| Field | Type |
|---|---|
| url | string. URL of the live demo. |
| title | string (optional). Display title. |

## Example payload

```json
{
  "type": "live_demo_embed",
  "url": "https://example.com"
}
```
