# Summary Box

Renders a condensed overview panel summarising article content at a glance.

## Surfaces

web, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| text | string. The summary narrative block. |

## Example payload

```json
{
  "type": "summary_box",
  "text": "A concise description of the content."
}
```
