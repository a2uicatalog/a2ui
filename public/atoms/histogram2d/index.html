Histogram2D

Counts of x,y points in a grid of 2-D bins (the Plotly histogram2d trace), drawn as a heatmap: d3 bin() is run once on x and once on y, the cell count is the number of points that fall in both bins, and the grid is handed to the heatmap atom, so it has the heatmap colour bar, the cell counts printed inside the cells and a hidden data table. The highest y bin is the top row. Use nbinsx and nbinsy for the number of bins (the real count is the nearest round step, as in d3), or leave them out for the Sturges default. At most 20,000 points are used and at most 40 bins per axis, each with a note.

Fields
FieldTypeRequired
xarray (required, numbers, at least 2 usable pairs with y; up to 20,000 used).required
yarray (required, numbers, same length as x).required
nbinsxinteger (optional, 3 to 40, the bin count asked of d3 for x; default Sturges).optional
nbinsyinteger (optional, 3 to 40, the bin count asked of d3 for y; default Sturges).optional
titlestring (optional, max 80).optional
x_labelstring (optional, max 40, named in the note under the grid).optional
y_labelstring (optional, max 40, named in the note under the grid).optional
scalestring (optional, a heatmap colour scale name such as Blues, Viridis or YlOrRd; default YlGnBu, light for few points and dark for many).optional
show_valuesboolean (optional, default true, prints each count in its cell).optional
show_colorbarboolean (optional, default true).optional
versioninteger (optional, default 1; a higher number draws as version 1 with a muted note).optional
