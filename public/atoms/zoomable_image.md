# Zoomable Image

Renders an image that magnifies when hovered over.

## Surfaces

web, google-meet-stage, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| image_url | string |
| alt_text | string |
| zoom_factor | float |

## Example payload

```json
{
  "type": "zoomable_image",
  "image_url": "https://example.com",
  "alt_text": "Descriptive alt text for accessibility",
  "zoom_factor": "Zoom factor"
}
```
