# Star Rating Input

Renders an interactive star rating component for user input.

## Surfaces

web, google-meet-stage, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| max_stars | integer |
| initial_rating | integer |
| name | string |

## Example payload

```json
{
  "type": "star_rating_input",
  "max_stars": 5,
  "initial_rating": 75,
  "name": "Star Rating Input"
}
```
