# Text Block

Plain text block rendered as a paragraph

## Surfaces

web, google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| text | string |

## Example payload

```json
{
  "type": "text_block",
  "text": "A concise description of the content."
}
```
