# Embed Google Slides

Renders an interactive presentation iframe viewer loading Google Slides resources.

## Surfaces

web, mcp-apps

## Fields

| Field | Type |
|---|---|
| presentation_id | string. Asset identifier for the slide file. |

## Example payload

```json
{
  "type": "embed_google_slides",
  "presentation_id": "Presentation id"
}
```
