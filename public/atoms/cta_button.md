# Cta Button

Full-width call-to-action button linking to a URL

## Surfaces

google-apps-script-web, mcp-apps

## Fields

| Field | Type |
|---|---|
| url | string |
| label | string |
| color | string (optional, hex) |

## Example payload

```json
{
  "type": "cta_button",
  "url": "https://example.com",
  "label": "Cta Button"
}
```
