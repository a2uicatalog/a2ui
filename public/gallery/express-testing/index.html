Express testing: where the data lives

This is a static export of the evidence behind our A2UI Express test programme (28 and 29 October 2026): raw model replies, saved payloads, scores, the content check and the renderer comparison. It has 2517 files and about 12 MB. Every link is relative, so it works from a local folder and as plain static pages.

Read this first. The samples are small: six briefs (T1 to T6), one to three repeats, one slice per run. The content check is one repeat of 72 cells. Atom-choice F1 is scored against answer key v2 and says which components were used, not what they say. Nothing here ranks models or formats, and nothing here confirms or refutes Google's "up to 80x". Model names (Sonnet, Haiku, Opus, Gemini, Jev, Clef) appear as the subjects that were measured.

Evidence labels

  • measured taken directly from a run or a review of the saved output.
  • computed derived by arithmetic from measured values (ratios, means, extracted tables).
  • sourced taken from a named public page (prices, Google's post).

Naming

Result and payload folders read slice__format__model__settings__runN, for example oracle-slice-3types__express__sonnet-5-5__temp0__run1. Slices: full catalogue, rule slice (family rules), oracle slices (built from the answer key, so a ceiling), tag slice, wrong-domain slice, random slice. Formats: express, json (Direct JSON), elemental. See README.md for method, how to re-score and licence.
