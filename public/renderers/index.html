Which renderer draws which atom

Every atom already says where it appears; this adds what draws it, measured per renderer. 573 public atoms, 7 renderers, 7 of them measured.

Flutter: Measured on a private, unpublished build of the renderer; it cannot be reproduced from a public commit.

Two dimensions, in plain words

Surface: where it appears

The place a person sees the atom: web page, MCP app, Android, PDF, Google Meet stage, and so on. This is the x-surfaces field of each atom.

Renderer: what draws it

The piece of software that turns the atom into pixels: React, Lit, Angular, CopilotKit, a2ui-vue, Flutter or Compose. This is the x-renderers field. One surface (the web) is drawn by several renderers, and one renderer can serve several surfaces.

For agents and tools

Each component in /catalogue/a2ui-atoms-v1.json and each atom in /spec.json carries an x-renderers object next to x-surfaces, one key per renderer. The full per-check data is /catalogue/renderer-matrix-v1.json.

{
  "x-surfaces": [
    "web",
    "mcp-apps"
  ],
  "x-renderers": {
    "react": {
      "status": "drawn",
      "reasons": [],
      "measured": "<date>",
      "measured_on": "shipped",
      "renderer_version": "<version>"
    },
    "...": "one key per renderer"
  }
}
