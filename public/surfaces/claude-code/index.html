Claude Code

Claude Code, via a mod. The a2ui-claude-code plugin draws these atoms as native terminal panes inside Claude Code: /a2ui payload.json, payloads from the a2uicatalog MCP server, animated progress bars for scripts (a2ui-progress build 42) and a long-job dashboard. Atoms this surface does not draw yet show a placeholder.

Install from the repository: claude --plugin-dir a2ui/claude-code-surface · source and README
