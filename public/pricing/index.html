Pricing, Rate Limits & Quotas

A2UI Atomic Catalog

Pricing, rate limits, and quota information for the A2UI Atomic Catalog.

Free Tier Limits

All developer endpoints and MCP tools are completely free to use with no API key or credit card:

  • /api/render: 50 requests per IP per day
  • /api/compose: 20 requests per IP per day
  • /ask: 60 requests per IP per day
  • /spec.json and catalog index: unlimited, cached via CDN

Zero-Cost Self-Hosting

Need higher volume? Deploy your own Apps Script renderer or Cloud Run instance in minutes with zero hosting cost beyond your Google account.
