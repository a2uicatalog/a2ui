# Policy: open for real agent use (search indexing, live query-time RAG/
# grounding), closed to bulk training-corpus harvesting. These are NOT in
# tension — a live agent answering a user's question uses ai-input, never
# ai-train, so this costs nothing on the actual discoverability/usability
# goal this file otherwise serves. Content-Signal is Cloudflare's emerging
# (2026, contentsignals.org) robots.txt extension for declaring PURPOSE, not
# just permission — it's a preference signal, not an enforcement mechanism
# (well-behaved crawlers honor it; nothing here stops a bad actor), same as
# every other robots.txt line. Named per-bot stanzas (identical rules to the
# wildcard) exist so some agent-readiness scanners can see "yes, we thought
# about you specifically," not because the rules genuinely differ per bot.
