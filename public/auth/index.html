A2UI Atomic Catalog

Authentication and security documentation for developers and AI agents integrating with the A2UI Atomic Catalog.

Public Unauthenticated Access

The primary MCP server (https://a2uicatalog.ai/mcp) and public REST endpoints (/api/compose, /ask, /spec.json) require no API key and no account signup. Clients can send requests immediately.
