## Issues and contributions

The fastest route for anything technical is the repository: [github.com/a2uicatalog/a2ui/issues](https://github.com/a2uicatalog/a2ui/issues). Bug reports, atom proposals and pull requests are all welcome there.

## Maintainer

The catalogue is built and maintained by [Curtis Krygier](https://www.linkedin.com/in/curtiskrygier). LinkedIn is the most reliable way to get a direct reply.

## Integration questions

If you are wiring an agent to the MCP server, the answers are usually already written down: the [OpenAPI spec](https://a2uicatalog.ai/openapi.json) describes every endpoint, and `GET /mcp` with `Accept: application/json` returns a live server descriptor listing every tool and its current rate limits. No API key or signup is required.

## Security

If you believe you have found a security issue, please report it privately through the GitHub repository's security advisory form rather than a public issue.
