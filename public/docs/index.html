A2UI Atomic Catalog — API Docs, OpenAPI Spec & MCP Server

Developer & Agent Documentation

Developer and API documentation for the A2UI Atomic Catalog. All developer resources are free, unauthenticated, and machine-readable.

Primary integration surface: the MCP server at https://a2uicatalog.ai/mcp — no API key, no signup, POST JSON-RPC 2.0 directly. Documentation questions: the docs MCP server at /mcp-docs. Contract: OpenAPI 3.1 specification. Packages: SDKs & client libraries. Guide: developer portal.

Sandbox and test mode

Sandbox server: https://a2uicatalog.ai/api/sandbox. It serves the render routes with the same code on its own allowance of 20 requests per IP per day, so test calls never spend the production one: POST https://a2uicatalog.ai/api/sandbox/api/render, .../api/render/batch and .../api/render/jobs. Every reply carries X-A2UI-Sandbox: true.

Production is also safe to test against: the REST endpoints hold no production data: /api/render, /api/render/batch, /api/render/jobs, /api/compose and /api/data are side-effect free, so a test call against production cannot change anything; its only cost is quota. To try payloads by hand, use the playground at play.a2uicatalog.ai. On the MCP server, every tool that stores, sends or deletes something is annotated readOnlyHint: false; the read-only tools are safe to call freely while building an integration.

REST Endpoints

POST /api/renderRender atom payload to standalone HTML page (50 req/day)
POST /api/composeNatural language prompt → typed atom blocks (20 req/day)
GET /ask?q=...Natural-language search over the atom catalog (60 req/day)
GET /api/data/{source}Declared data source proxy (data-sources.yaml)
GET /spec.jsonFull atom vocabulary (573 atoms) with all field contracts
GET /catalogue/atoms-json-schema.jsonStrict JSON Schema for constrained agent decoding
GET /catalogue/index.jsonCompact catalog selection menu

MCP Servers

  • Product MCP Server: https://a2uicatalog.ai/mcp — tools for composing, rendering, and publishing UI atoms.
  • Documentation MCP Server: https://a2uicatalog.ai/mcp-docs — tools (search_docs, list_docs) for querying documentation.
