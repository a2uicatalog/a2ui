# Third-party notices

The `d3pack` macros are Python re-implementations. Several of them follow the algorithms of the d3 libraries listed below: some are line-for-line ports (for example the treemap squarify and the tick maths), others follow the same method with their own code (circle packing, sankey layout, directed chord). Where code is derived from d3, the licence below applies and its copyright notice is retained here.

A conformance test kept outside this repository installs the real d3 packages only to generate reference numbers; they are not part of this pack. Licence texts below are copied from the files that ship in those packages (installed at the exact versions pinned in `conformance/package.json`).

The file-by-file derivation audit is in `LICENCE-AUDIT.md` (2026-11-14); the "Used for" column below is the intended mapping, not a legal analysis.
