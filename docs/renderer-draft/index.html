Which renderer draws which atom

A new, separate dimension of the catalogue. Every atom already says where it appears; this adds what draws it, measured per renderer. 573 stable atoms, 7 renderers (one not measured).

Flutter: Build provenance was not recorded for this run.
React, Lit, Angular, CopilotKit, a2ui-vue: Measured on a pre-merge build, re-measurement pending.

Two dimensions, in plain words

Surface: where it appears

The place a person sees the atom: web page, MCP app, Android, PDF, Google Meet stage, and so on. This is the existing x-surfaces field. It does not change.

Renderer: what draws it

The piece of software that turns the atom into pixels: React, Lit, Angular, CopilotKit, a2ui-vue or Flutter. This is the new x-renderers field. One surface (the web) is drawn by several renderers, and one renderer can serve several surfaces.
