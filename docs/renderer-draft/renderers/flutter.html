Honest notes

  • Partial coverage: only a part of the atoms are ported to native Flutter widgets. Text parity with the web painter was checked on the atoms listed in the parity sweep; the Basic lane was not measured by us; no device run. Measured on a private, unpublished build, after the lane merges.
  • Partial coverage: 501 of 573 atoms draw natively; 30 draw only through Basic components; 37 draw nothing; 5 are not measured (2 with an invalid example, the rest without an example).
  • Text parity with the web painter was checked on 279 atoms; 22 of those miss at least one web word in Flutter. The check compares visible words, not layout or pixels. For atoms with several cases the worst case counts.
  • No device run: everything ran in the headless widget-test engine. An independent 12 Nov audit of 40 ported atoms found visible drift in about 16, so Native here means the port draws the lane example, not that it matches the web look.
